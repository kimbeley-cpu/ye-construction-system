1Checklist 检查项目

Tap ✓ when it is done, ✗ when there is a problem (say what is wrong), N/A when it does not apply to this room (add a note if useful). Answer every item on this stage. To change an answer, tap a different one. “Select all” ticks every item still empty; “Clear all” empties the whole section (tap it twice).
完成点 ✓，有问题点 ✗ 并写明原因，不适用点 N/A（可写备注）。本阶段每一项都要填。要改答案，直接点另一个选项。“全部选择”把还没填的项全部打 ✓；“全部取消”清空整段（要点两次）。

填表时自动检查，点一行可跳到该处。红色项目必须改好才能提交。

6Office Check 办公室审核 (office use 管理填写)

Your sheet saves automatically on this device, and to the office once you are signed in. One sheet is one room at one stage. After you submit, a new sheet opens with the same site, floor, stage, inspector and pipes filled in, ready for the next room.
表格自动保存在本机，登录后也会保存到办公室。一张表 = 一个房间的一个阶段。提交后会开一张新表，地址、楼层、阶段、检查人和管材都保留，接着填下一个房间。
